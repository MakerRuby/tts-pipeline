# 通用发音词典（跨项目）

> 作用：S4 发音校准先查这张表。§B 同时也是 `scripts/polyphone_scan.py` 的数据源（脚本读取 §B 表格的第一列）。
> 不负责：单个项目里的专名和术语，这些记在项目目录的 `lexicon.md`。平台标注语法见 platforms.md §5。
> 读者：执行 skill 的 agent；`polyphone_scan.py`。
> 更新触发：S9 复盘时，把跨项目通用的词条提升到这里。增删 §B 的条目时，保持表格格式不变（第一列只写一个汉字）。
> 这张表是复利资产：项目做得越多，返工越少。同一个术语预计会复用 10 次以上时，还要录入平台的发音词典（如 ElevenLabs Pronunciation Dictionary、MiniMax pronunciation_dict）。

## C. 数字与符号读法约定（统一规则，不让模型自由发挥）

| 类型 | 写法 | 示例 |
|---|---|---|
| 年份 | 逐位读 | 2026 → 二零二六年 |
| 小数 | 用"点" | 3.5 → 三点五 |
| 百分比 | 写成汉字 | 12% → 百分之十二 |
| 金额 | 读出完整单位 | ¥4,800 → 四千八百元 |
| 电话、编号、房间号 | 逐位读，1 读作"幺"由项目决定 | 110 → 幺幺零 |
| 负数与温度 | "零下"或"负" | -5℃ → 零下五度 |
| 比分与比例 | "比" | 3:2 → 三比二 |
| 范围 | "到"或"至" | 5–10 → 五到十 |
| 单位 | 写全称 | km → 公里；GB → G B 或"吉字节"（由项目决定） |
| 网址、邮箱 | 口播时改写成说法 | example.com → example 点 com |
