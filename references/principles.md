# 真人感第一性原理与工作方法

> 作用：解释"听众凭什么判断真人"，并由此推出本 skill 的工作方法和每一阶段存在的理由。
> 不负责：具体操作技法（见 `craft.md`）、平台语法（见 `platforms.md`）、验收数字（见 `qa-delivery.md`）。
> 读者：执行本 skill 的 agent；想理解"为什么这样做"的用户。
> 更新触发：出现推翻某一层判断的新研究或新模型能力时。
> 依据：2026-10 调研（听辨研究、合成语音研究、实践者经验），关键来源附在文末。

## 1. 听众是怎么判断"真人"的

听众脑子里有一个说话人模型：这是一个**有身体**（会呼吸、会累）、**有心思**（边想边说、有说话对象）、**身处某地**（房间、话筒距离）、**处在某种关系里**（和听众、和其他说话人）的人。
任何一层出现与这个模型不符的信号，就会让人觉得"有 AI 味"。

所以**真假难辨 = 各层之间没有矛盾 + 这个人在这个场合说这些话本身可信。**
单层做到极致没有用。最弱的一层决定整体听感，这是"木桶效应"。

| 层 | 真人什么样 | AI 怎么露馅 | 主要在哪一阶段解决 |
|---|---|---|---|
| L1 意图 / 写作 | 说给某个具体的人听；边想边说；信息有轻重 | 书面长句、信息平铺、没有说话对象 | S3 脚本 |
| L2 情绪 / 语用 | 情绪跟着"想法"走，有起伏 | 单句情绪对，整段情绪不对；情绪与语义打架 | S2 说话人卡 + S3 表演 |
| L3 韵律 | 语速和音高随信息量变化；焦点词抬高；停顿长短不一，有呼吸 | 每句结构相同；停顿只看标点，而且一样长 | S3 + S6 抽卡 |
| L4 发音 | 不读错 | 多音字、数字、专名读错（"棒读感"很大一部分其实来自读错） | S4 |
| L5 嗓音 / 身体 | 气息、疲劳、口腔细节在变化 | 从不疲倦；每次爆破音都一样；笑声前没有吸气 | S2 音色 + S8 后期 |
| L6 空间 / 录音链 | 有房间感、有底噪，话筒距离稳定但不完美 | 绝对干净；静音像被"关掉" | S8 后期 |
| L7 交互（仅对话 / 实时） | 换人说话的间隔集中在 0–200ms（10 种语言一致）；有附和；约 5% 的时间两人同时说 | 换人间隔均匀；没有附和；回应延迟长 | 场景卡 C / D |

两条已经被研究证实的事实：
- 克隆声音在盲听中已经和真人**统计上无差异**（UCL 2025：被判为真人的比例，克隆 0.58，真人 0.62）。从零生成的"通用"声音仍容易被识破（0.41）。所以**音色来源**是第一个关键决策。
- 模型主要根据**文本**推断情绪（CosyVoice 3 论文、ElevenLabs 文档、豆包 context_texts 都是这个机制）。所以真人感的上限在写稿阶段就定了，调参数只能在这个上限以内修补。

## 2. 当前高手做法的天花板，以及提升空间

现在主流的高手流程是：口语化改写 → 加情绪标签 → 抽卡（同一句生成多次挑最好的）→ 发音词典 → 轻后期。这套流程有效，但从上面的分层模型看，还有 6 处可以提升：

1. **先写人，再写词**（针对 L1–L2）。
   多数做法是改表面：加"嗯"、加标签。根本问题是声音背后没有一个"有心思的人"。
   改进：动笔前先写**说话人卡**：他是谁、对谁说、为什么现在说、知道多少、和听众是什么关系、身体状态如何。再为每段写一句**意图**："这段想让听众感到 / 做到什么"。
   标签由意图推出来，而不是拿来装饰。这就是演员说的"潜台词"。模型会读上下文，把意图写进去就是给它最有效的输入。

2. **整体一致比局部出彩重要**（针对 L3、L5）。
   听众对"前后不一致"比对"平淡"敏感得多。逐句挑最出彩的一条，最后会变成拼贴。
   改进：抽卡以**段落**为单位（长度见 `craft.md` §抽卡与生成）；挑的标准是"和前后衔接自然"，而不是这句单独听最好。尽量让模型能看到前后文（previous/next text、整段对话一次生成）。

3. **每一处不完美都要有原因**（针对 L1、L5）。
   故意弄乱会被听出来（McGregor："fake sound is messy on purpose"）。
   改进：填充词、呼吸、自我修正只放在**说话人确实会卡住的地方**：在思考、转折、长句之前。并且限制密度（见 `craft.md`）。
   检验方法：每一处不完美都要能说出原因，说不出就删。

4. **跟真人参照比，不凭感觉**（全层）。
   "听着还行"不是验收标准。
   改进：开工时找一段 30–60 秒、同类型的**真人参照录音**。所有选择都对照它。样片要和它混在一起盲听，被判为真人的比例不能明显更低（这是 Lavan 2025 用的研究范式，这里改成小规模版）。

5. **机器抓错，人耳判真**。
   ASR 回检字错率（CER）、拼音比对、UTMOS 这类工具能可靠抓出**缺陷**（漏字、读错、噪声）。但两段都没有缺陷时，它们**选不出哪段更像人**（arXiv 2609.13150）。
   改进：先让自动闸门筛掉缺陷，人耳只用来判断机器抓不到的 L2、L3、L5，不把时间浪费在找错字上。

6. **把成果沉淀成资产**。
   发音词典、说话人卡、音色参数、验证有效的标签写法，都是可以跨期、跨集复用的资产。项目做得越多，返工越少。

## 3. 返工从哪里来（"一次成型"靠什么）

| 返工来源 | 典型例子 | 对策（对应阶段） |
|---|---|---|
| 上游信息没给全 | 读音没确认；画面时长不知道；没拿到克隆授权 | S0 开工问卷 + 素材清单一次收齐 |
| 中途改了锁定项 | 换模型、换音色、换语速，导致前后不一致 | S1 锁定表；要改必须走变更流程，并列出哪些产出因此作废 |
| 缺陷发现太晚 | 整本书做完才发现某个多音字一直读错 | S5 样片闸门：用 30–60 秒全流程验证；S7 分批 QA |
| 平台或政策事实过时 | 用了已经停服的接口；授权条款改了 | 涉及平台的步骤先联网核实 |
| 漏了合规 | 没加 AI 标识；克隆没有拿到单独同意 | S1 就定标识方案；S2 授权登记 |

## 4. 工作方法口诀

**先定人，再写话；先样片，后批量；机器抓错，人耳判真；不完美要有因；资产全留档。**
