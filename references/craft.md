# 技法手册（音色 · 写稿 · 表演 · 抽卡 · 后期）

> 作用：S2/S3/S6/S8 的具体做法和数值参考。
> 不负责：解释原理（见 principles.md）；平台语法（见 platforms.md §5）；验收标准（见 qa-delivery.md）。
> 读者：执行 skill 的 agent。
> 更新触发：S9 复盘时发现有效的新技法，或某条技法反复失效。
> 证据标记：【一致】多个来源一致；【厂商】厂商文档；【经验】单一来源或经验值，建议在 S5 样片上验证后再用。

## §音色（S2）

**参考音频（克隆用）**【一致】
- 安静房间，单人，话筒链路始终不变；不加 EQ、不压缩、不降噪；先录 10 秒房间底噪，确认底噪够低。
- 时长：零样本克隆 10–30 秒（豆包建议 14–30 秒，MiniMax 约 10 秒）；专业克隆按平台要求，ElevenLabs 建议 YouTube 用途 10–15 分钟，有声书 20–30 分钟，超过 60 分钟收益递减。
- **情绪基调要和成品一致**。v4 和豆包的文档都提醒：情绪丰富的参考音频，多次合成时情绪会漂移。不同用途分别建子克隆，比如"讲解版""讲故事版"。
- 模型会忠实复刻瑕疵，包括爆破音、齿音、音量波动、清嗓。不想被学去的东西，录的时候就别带进去。
- 声音克隆需要本人单独同意，见 `qa-delivery.md` §授权。

**音色库挑选**：用 S2 的试音文本，每个候选都生成一遍，和真人参照混在一起盲选。只听平台自带的 demo 不算数，demo 都是精选过的。

**Voice Design 描述**【厂商】
- 顺序：语言/口音 → 年龄性别 → 音质 → 人设 → 情绪 → 节奏。
- 写具体、可以听出来的特征。不要用"好听""有磁性"这类空词。不要写 reverb、phone 这类效果词。
- 预览文本要符合这个人设，越长越稳。每次一般会出 3 个候选。
- 例：`35岁男性，普通话略带北方口音，中低音区，声音有颗粒感，像深夜电台主持在和一个老朋友聊天，语速偏慢，句尾常常放松下沉。`

**参数起点**（ElevenLabs）【厂商】
- 叙述类：Stability 0.4–0.7；对话或角色：0.2–0.4。Similarity 0.75 左右，拉高会放大源音频的噪声。
- v4 只剩 Stability 和 Similarity 两项；PVC 的 Clone Strength 从 0 开始往上调。
- 其他平台：情绪强度、语速等参数都先用默认值，在 S5 里一次只改一个变量。

## §写稿（S3 · P1）

**写给耳朵**【一致】
- 一句话只讲一件事。中文单句尽量不超过 25 字，超过就加逗号断开，或者拆成两句。
- 书面词换成口语词（因此→所以，进行讨论→聊聊）；用"你"直接称呼听众；可以先给结论，再解释原因。
- 适当加设问，比如"为什么？因为……"；具体胜过抽象，用例子代替定义。
- 先做文本归一化：数字、单位、符号、网址、缩写全部写成读法（规则见 `lexicon.md` §C）。

**语速参考（中文，字/分钟）**【经验】

| 场景 | 语速 |
|---|---|
| 讲解或有声书叙述 | 200–250 |
| 轻松对话或播客 | 240–300 |
| 广告或口播快节奏 | 280–330 |
| 情绪沉重、需要强调 | 160–200 |

估算时长 = 字数 ÷ 语速，再加上停顿时间。写进 `spec.md`，S5 用实测值校正。

## §表演（S3 · P2）

**先写意图，再写标签**：每段一句意图，写成"让听众 ___"。标签从意图推出来。写不出意图的段落不加标签，保持平叙。

**密度上限**【经验，S5 验证后可以调整】

| 元素 | 上限 |
|---|---|
| 情绪 / 风格标签 | 每段（一次语气转换）最多 1 个。解说和播客大约每分钟 2–4 处；有声书只在情节转折处标，大多数段落保持平叙（英文参考值：1500 词约 20–40 处） |
| 非语言音（笑、叹气、呼吸） | 每分钟 2 个以内，只放在有原因的地方 |
| 填充词（嗯、呃、那个、就是说） | 解说每分钟 2 个以内；播客**每人**每分钟 3 个以内；有声书旁白不放，只在角色对白里放 |
| 省略号 | 每段 2 个以内，多了显得做作 |
| 自我修正、假起头（"它是……它确实是"） | 每分钟 1 个以内，只放在情绪激动或思考的地方 |

**标点控节奏**【一致；中文的效果要在各引擎上实测】
- 停顿由短到长：顿号 < 逗号 < 分号 < 句号 < 换行 < 空行。经验值：逗号 0.2–0.4 秒，句号 0.4–0.6 秒，段落之间 0.8–1.2 秒。
- 省略号表示迟疑；破折号表示转折或插入；问号让句尾上扬。有的引擎不识别中文破折号或书名号，要在 S5 测一下。
- 重音：中文没有通用的重读标记，只有部分平台支持（CosyVoice 的 `<strong>`）。通用做法是把焦点词放到句末，或者单独成句："关键就一个词：节奏。"

**语境提示**【厂商】
- 叙事式提示（"她颤抖着问"）能稳定情绪，但会被念出来。可以在后期剪掉，或者改用平台的语境字段（豆包的 context_texts、ElevenLabs 的 previous_text）。
- 标签写**可以听出来的嗓音特征**，比如 `[low, gravelly voice]`。不要写画面动作，比如 `[standing]`。标签要符合音色的气质，不要让冥想类的声音去喊。

**刻意的凌乱会被识破**：每一处不完美都要能说出原因。说不出原因就删掉。

## §对话（场景 C · P5）

- **角色功能**：两个人的知识水平或立场要不同。每轮长度要长短交替，不要轮轮一样长。
- **附和**（对、嗯哼、真的假的）：大约每 3–5 句插一次，放在对方长句的中间或结尾。
- **插话**：每 2–3 分钟 1–2 次，用"——"截断前一个人的话。
- **笑**：只放在真的好笑的地方。
- **轮次间隔**（需要手工拼接时）【有研究依据】：
  - 大部分取 100–300 毫秒，加一些随机抖动；
  - 思考后再回答的地方取 400–800 毫秒；
  - 抢话或接话的地方取 −100 到 0 毫秒（轻微重叠）。
  - 不要全部用同一个固定值。

## §抽卡与生成（S6）

- **分段**：
  - 以段落为单位，一般 1–3 句；中文厂商有建议约 300 字一段。同一段内情绪保持一致。
  - 切得太碎听起来像机器，切得太长容易跑飞。
  - 平台硬上限：ElevenLabs 单次请求不超过 2000 字符。本机自回归模型建议不超过 200 字符。
- **抽卡**：每段生成 3 条。先淘汰有缺陷的（漏字、读错、杂音），再按"和前后段的衔接"选一条。
- **前后文**：能传 previous_text / next_text 的平台都要传。对话能整段生成的就整段生成。
- **局部修复**：只重新生成有问题的那一段，不要整篇重来。大约一半的问题重新生成一次就能解决【厂商】。
- **漂移监控**：长项目每完成约 10%，就把当前段和第一段的选定条放在一起对比着听。有条件的话，计算说话人相似度（SIM）。

## §后期（S8）

处理顺序如下，原则是宁轻勿重【单源，混音工作室；与中文实践者的说法一致】：
1. **剪辑**：
   - 拼接处做 10–50 毫秒的交叉淡化；
   - 段落之间保留真实的换气或房间底噪，**不要放数字静音**（绝对的静音像被"关掉"，是 AI 征兆之一）；
   - 没有底噪时，铺一层约 −60 dBFS 的房间底噪。
2. **不要对 AI 干声做降噪**：AI 输出本来就几乎没有底噪，再降噪只会损失谐波、抹掉呼吸。
3. **减法 EQ**：
   - 80–100 Hz 低切；
   - 在 2–4 kHz、6–9 kHz 附近找刺耳的共振点，衰减 2–5 dB；
   - 慎用整体提亮。
4. **去齿音**：亮的嗓音在 6–8 kHz，低沉的嗓音在 5–7 kHz，衰减 4–7 dB。可以串两个效果温和的去齿音器。
5. **压缩**：串联，每级 2–4 dB；或者用并联压缩。
6. **空间感**：用 send 挂一点很淡的混响（低切 300 Hz、高切 8 kHz、预延迟 20–40 毫秒）。目的是让声音"在一个房间里"，不是让人听出混响。
7. **呼吸**：补呼吸声要谨慎，只在长句前的停顿里补，比人声低约 20 dB，前后各做 50 毫秒淡入淡出。广告类作品不建议补。
8. **配乐**：
   - 人声开口时把配乐压低（ducking），参考值是比人声低 15–20 dB；
   - 具体压多少以听感为准，这条没有找到可靠来源；
   - 数字人项目要等对完口型再混配乐。
9. **响度**：调到 `spec.md` 锁定的目标值（规范见 `qa-delivery.md` §交付）。
