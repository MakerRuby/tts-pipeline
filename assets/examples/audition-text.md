# 试音文本（S2 候选音色盲选 / S5 参数对比用）

> 作用：用同一段文本测试每个候选音色，覆盖最容易露馅的几种情况，方便公平比较。
> 用法：按场景挑一段，或替换成项目里最难的一段原文（S5 优先用真实稿件）。数字已经写成读法；多音字处在 S4 之前保持原样，用来测平台的默认能力。

## 通用段（约 40 秒）

说实话，我第一次听到这个结论的时候，也不太信。
你想啊，一个只有零点五克的东西，怎么能撑起二十公斤的重量？
后来我们重复了三次实验——结果都一样。
这就是今天想跟你聊的：为什么"轻"和"弱"，根本不是一回事。
顺便说一句，这个项目的 API 文档和 GitHub 仓库，我放在简介里了。

（覆盖：自我修正式开头、设问、数字、破折号停顿、多音字"重""只""和""都"、中英夹杂、结论句。）

## 叙事段（有声书）

雨下了一整夜。
她站在门口，手里攥着那封没拆开的信……
"你还回来吗？"她轻声问。
没有人回答。只有风，把门吹得吱呀作响。

（覆盖：旁白与对白切换、省略号迟疑、低声、情绪转折。）

## 对话段（播客，两人）

A：所以你的意思是，这个方法其实早就有了？
B：对，早在九十年代就有人提过，但是——
A：等等，那为什么现在才火？
B：嗯……好问题。我觉得主要是算力终于跟上了。
A：哈，原来如此。

（覆盖：插话、附和、思考停顿、笑。）
